# 系统交易与周期活跃统计修正

用户已确认只修统计、不重采、不修改原始文件；HTML 看板稍后再做。

## 方案

不重写 Parquet 或修改 manifest/checkpoint。周/月周期统一使用 YYYY-MM-DD 日期键，维持周期内独立发送地址精确去重，保留零活动周期与部分周期标记。

TxDAG 使用保守的已知主网规则：发送地址 0x8eece8cb98dc9aaddb37a8177e4615469d771631、接收地址 0xda90000000000000000000000000000000000000、legacy type 0、有效十六进制 calldata 至少包含 ABI 头且 selector 为 0x5517ed8c、value 为零、receipt 成功且 effectiveGasPrice 为零、位于区块最后一笔。只凭接收地址或零费用不排除交易；其他发送方、失败、缺少费用证据等均保留原有分类。

采集规范化与报告按分区关联时应用相同规则。旧数据中的 is_system=false 在报告临时磁盘表中纠正，日志关联使用相同纠正视图。新增 system_tx_dag 技术分类，系统费用组包含两类协议交易，非系统活跃、项目/方法/接收方/发送方榜和留存一致剔除 TxDAG。普通用户 deposit 不变。

分析 metadata 增加 system_rules_version，说明采集时字段与分析时分类可能不同；配置 identity 与原始校验规则不变。固定已知发送地址不声称穷尽其他协议活动或未来发送地址轮换。

## 验收

先观察旧实现的回归失败，再修复：跨周/月精确去重、部分/零活动周期；TxDAG 正例和条件逐个缺失的反例；旧版 Parquet 全管线（含事件、费用、榜单）重新分类；原始文件、manifest、checkpoint 不变。保留现有低内存分区处理，运行完整测试。不在本机仅凭旧 analysis.json 生成修正版主网结果。
